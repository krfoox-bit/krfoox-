KRFOOX — новый отдельный комплект на основе исходных файлов пользователя.

client.html — исходный дизайн/текст клиентского сайта сохранены; изменён только запрос занятых слотов: вместо чтения клиентом таблицы bookings используется функция krfoox_booked_times, которая возвращает только дату и время.
admin.html — исходный файл панели владельца скопирован без изменений.
database.sql — общая схема/права Supabase для таблиц, используемых обоими HTML.
Все файлы отдельные; исходные загруженные файлы не перезаписаны.

Установка:
1. В проекте Supabase https://wjvuffwegkyrongdxyni.supabase.co откройте SQL Editor -> New query.
2. Вставьте database.sql и нажмите Run.
3. Опубликуйте client.html как главную клиентскую страницу.
4. Опубликуйте admin.html отдельно, например /admin.html.
5. В Supabase Auth должен существовать пользователь с email krfoox@gmail.com и правильным паролем.

Проверки: HTML-структура и синтаксис JavaScript проверены локально. SQL не выполнялся на реальном проекте, соединение с Supabase ещё нужно проверить после установки.
Важное ограничение: существующие бронирования не удаляются, но SQL заменяет RLS-политики для перечисленных таблиц и storage.objects-политики, относящиеся к указанному набору.
