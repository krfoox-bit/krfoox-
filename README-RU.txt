KRFOOX — комплект для публикации

Файлы:
- index.html — клиентский сайт записи.
- admin.html — панель владельца.
- schema.sql — схема общей базы Supabase.

ПОРЯДОК ЗАПУСКА:
1. В Supabase выберите нужный проект и откройте SQL Editor.
2. Вставьте весь schema.sql и нажмите Run. Перед запуском убедитесь, что выбран правильный проект.
3. Разместите index.html на клиентском сайте как index.html.
4. Разместите admin.html на отдельном сайте/проекте как index.html (или откройте /admin.html в одном проекте).
5. В Supabase Authentication создайте администратора с email и паролем.
6. Войдите в панель этим аккаунтом.

Оба HTML используют один и тот же Supabase URL и публичный ключ. Записи клиентов находятся в общей таблице bookings; статус/расписание — salon_settings; список филиалов — sites.

ВАЖНО: политика даёт чтение/изменение записей любому аутентифицированному пользователю Supabase. Не создавайте дополнительные аккаунты для посторонних. Публичные посетители могут создавать записи и читать статус/расписание и список сайтов. Это статический комплект; публикация на Vercel/Netlify и проверка реального подключения не выполнялись.
